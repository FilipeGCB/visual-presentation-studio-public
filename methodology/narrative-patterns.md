# Narrative Patterns

The library stores reasoning structures, not decks with replaceable text.

## Problem → Evidence → Cause → Solution → Impact

Use when the audience must accept both the problem and the proposed response. Establish stakes, prove scale, explain causality, show the intervention, and make the expected impact traceable. Avoid when diagnosis is already settled or evidence cannot support causality.

## Today → Tension → Change → Future

Use for transformation narratives. Make the tension concrete, show what changes operationally, and render the future as a consequence rather than wishful imagery. Avoid when “before” and “after” are artificial or the path is absent.

## Context → Diagnosis → Alternatives → Recommendation

Use for executive decisions. State evaluation criteria before comparing alternatives and connect the recommendation to them. Avoid presenting fake alternatives whose outcomes were predetermined.

## Overview → Exploration → Drill-down

Use when the audience must form a mental model and then pursue different questions. Keep global orientation visible and provide clear return/reset paths. Avoid when the audience needs one controlled persuasive sequence.

## Validation

- One-sentence test: “This unit exists to ______.”
- Removal test: “If this unit is removed, what important understanding disappears?”

Narrative repetition must deepen meaning, not reproduce the same layout and claim.
