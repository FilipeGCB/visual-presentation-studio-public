# Narrative and Experience Selection

Choose the narrative before components and the experience before stack.

## Thesis first

Write a thesis as the single understanding the audience should retain. It must be specific enough to select evidence and reject irrelevant material. If the source supports several competing theses, expose the choice in Gate 1.

## Narrative patterns

| Pattern | Use when | Avoid when |
|---|---|---|
| Problem → Evidence → Cause → Solution → Impact | A problem must be proved, explained, and resolved. | The audience already accepts the diagnosis and needs comparison or execution detail. |
| Today → Tension → Change → Future | The story is a transformation with a meaningful before and after. | The future state is speculative or unsupported. |
| Context → Diagnosis → Alternatives → Recommendation | An executive decision requires traceable options and a recommendation. | There is no real choice or the conclusion is already mandated. |
| Overview → Exploration → Drill-down | Different users need to investigate the same system or dataset. | A presenter must control one persuasive sequence. |

Combine patterns only when each transition has a clear narrative purpose.

## Experience modes

### Traditional / 16:9

Use for sequential exposition, meetings, controlled pacing, presenter-led argument, and a stable display surface. Each screen should make one meaningful move while remaining understandable without speaker notes when the delivery context requires it.

### Scrollytelling

Use for continuous editorial narratives, asynchronous reading, vertical progression, mixed desktop/mobile use, and moments where sticky visuals or progressive reveals clarify change. Preserve semantic reading without JavaScript.

### Exploratory / Interactive

Use when the audience's questions vary and filters, comparisons, tabs, drill-down, maps, flows, organograms, or detail states increase understanding. Provide orientation, reset, return, and state feedback.

### Hybrid

Use when a controlled thesis benefits from a bounded exploration moment. Keep the transition explicit; do not combine modes merely to appear sophisticated.

## Storyboard contract

For every screen or block, record purpose, content, composition, asset, functional motion, and the message that must remain.

- One-sentence test: “This screen or block exists to ______.”
- Removal test: “If this is removed, what important understanding is lost?”

Remove any unit that cannot answer the first or produces no meaningful loss in the second.

## Narrative QA before build

- The opening frames the question or stakes.
- Evidence is attached to the claim it supports.
- No step assumes knowledge the audience does not have.
- Repetition creates emphasis rather than padding.
- The conclusion resolves the thesis and identifies the intended decision or understanding.
