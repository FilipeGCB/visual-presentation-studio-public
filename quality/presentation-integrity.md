# Presentation Integrity Check

Answer after the correction loop and before `READY FOR USER REVIEW`.

## 1. Can a person understand the message without knowing the project beforehand?

Record the evidence from the opening, transitions, labels, explanations, and conclusion. If essential context is missing, return to Narrative QA.

## 2. Does the visual treatment make the message clearer than text alone?

Identify where hierarchy, composition, image, diagram, chart, interaction, or motion improves comprehension. If the visual merely restyles text, reconsider the design.

## 3. Is anything present only to appear sophisticated?

Name any suspect effect, component, asset, visualization, or interaction. If the answer is yes, readiness is denied until it is removed, simplified, or explicitly justified by a communication function and revalidated.

## 4. Are the approvals and evidence claims exact?

Confirm that direction approval was not relabeled as asset approval, that applied assets were validated in composition, and that every desktop or mobile QA claim names the exact build, route, and evidence level. If any claim overstates its evidence, correct the record before readiness.
